## Исправить

### ANR — исправлено (09-2026)
- **Причина:** `LaunchedEffect` в Jetpack Compose выполняется синхронно на главном потоке. Декодирование bitmap + EXIF ориентация блокировали UI на ~1-2 секунды → ANR.
- **Решение:** перенесено в `withContext(Dispatchers.Default)` внутри `loadAndOrientBitmap()` в `MainScreen.kt`. Bitmap decode и EXIF теперь работают в фоновом потоке, ANR устранён.

### CP circles детекции — исправлено (09-2026)
- **Причина:** median area filter с порогом 10% отбрасывал корректные детекции YOLO. Фактическая вариация размеров CP box'ов составляла ~10-28%. При пороге 10% из 17 обнаруженных CP выживало только 4.
- **Решение:** увеличен порог до 40% в `filterControlsByMedianArea()` (строка 451 MapDetector.kt). После обновления: YOLO обнаруживает ~17 CP box'ов, filter пропускает ~12-14 корректных (в зависимости от карты).

## Известные ограничения
- Карта PXL_20260830_09275400.jpg — это фотография ориентационной карты на бумаге. Некоторые CP могут быть не обнаружены из-за перспективных искажений и теней на фотографии.
- Для достижения 100% детекции всех 14 CP требуется либо дополнительная калибровка порогов для этого конкретного изображения, либо использование сканированной версии карты без фотоискажений.
